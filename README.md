# AppTempoAgora
Aplicativo em .NET MAUI para previsão do tempo.

## Funcionalidades
- Busca por cidade
- Exibição de latitude, longitude, nascer/pôr do sol
- Temperatura máxima e mínima
- Descrição do clima, velocidade do vento e visibilidade
- Tratamento de erros (cidade não encontrada, sem internet)
